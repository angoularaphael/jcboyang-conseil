# Vidéo hero (accueil)

Placez votre fichier vidéo ici :

- `hero-accueil.mp4` — format MP4, H.264, sans son (lecture en boucle automatique)
- Résolution recommandée : 1920×1080 ou 1280×720
- Durée : 15–45 secondes en boucle
- Poids cible : &lt; 8 Mo pour un chargement rapide

L’image d’attente (poster) est définie dans `src/data/hero-media.ts`.

Pour héberger la vidéo ailleurs (CDN), définissez `PUBLIC_HERO_VIDEO_URL` dans `.env`.
